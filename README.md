# WhackEm

**WhackEm** is a simple web-based game built using HTML, CSS, and JavaScript.  
Players click on moles as they appear to score points, with all results stored locally in the browser.

---

## Features
- Interactive gameplay with dynamic mole animations  
- Local storage-based leaderboard for score tracking  
- Full CRUD functionality (Add, View, Edit, Delete scores)  
- Responsive design for mobile, tablet, and desktop  
- Two-page structure: Game and Leaderboard

---

## Technologies Used
- **HTML5** for structure  
- **CSS3** for layout and responsive design  
- **JavaScript (ES6)** for game logic and storage management  
- **Web Storage (localStorage)** for data persistence  

Have a good time and relive that arcade experience.
